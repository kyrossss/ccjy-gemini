# 春城嘉叶会籍方案

> 方案版本：`membership-ecosystem-v1.0`   
> 核心主张：从喝茶人，到爱茶人，再到茶文化参与者、品牌收藏家与共创者。

## 一、会籍定位

春城嘉叶会籍不是单一的折扣卡，而是一套围绕茶、器、内容、活动与收藏建立的长期会员关系。

会员在品牌内拥有三类独立账户：

- **成长值**：用于年度会籍等级与成长进度。
- **积分**：用于适用订单抵扣、商品兑换和活动兑换。
- **嘉叶币**：仅用于本人在适用订单中抵扣，不提现、不转让、不赠送。

三类账户分别记账，来源、用途和回退规则互不替代。

## 二、会籍结构

### 1. 年度会籍

年度会籍按账户年度成长值评定，注册后自动成为普通会员。年度会籍用于体现当期活跃度、消费贡献和品牌参与度。

| 会籍 | 成长值门槛 | 积分倍率 | 会籍关键词 |
| --- | ---: | ---: | --- |
| 普通会员 | 注册即可 | 1 倍 | 开始了解春城嘉叶 |
| 银卡会员 | 10,000 | 1.2 倍 | 日常品饮 |
| 金卡会员 | 30,000 | 1.5 倍 | 稳定相伴 |
| 白金会员 | 80,000 | 1.8 倍 | 品鉴与器物 |
| 黑金会员 | 200,000 | 2 倍 | 收藏与共创 |

### 2. 终身身份

终身身份按账户累计净实付消费金额和已认证记录判定，不因年度会籍变化而失效。

| 终身身份 | 累计消费门槛 | 积分倍率 | 核心价值 |
| --- | ---: | ---: | --- |
| 终身白金会员 | 600,000 元 | 2.5 倍 | 永久白金身份、年度会员礼、优先参与品牌活动 |
| 终身黑金会员 | 1,000,000 元 | 3 倍 | 专属收藏编号、私人茶会、品牌共创、新品研发体验 |

同时具备年度身份与终身身份时，积分倍率按账户内适用的更高身份执行。

## 三、会员权益

### 普通会员

- 注册即可加入。
- 享有基础积分、商品购买和基础活动参与资格。
- 获得生日祝福。
- 可查看个人成长值、积分和嘉叶币账户。

### 银卡会员

- 享有会员生日礼。
- 寄售成交服务费按 9% 执行。
- 优先报名普通茶会。
- 获得专属会员标签。
- 积分按 1.2 倍累计。

### 金卡会员

- 新品优先购买。
- 新茶试饮资格。
- 会员专属活动。
- 专属客服服务。
- 寄售成交服务费按 8% 执行。
- 积分按 1.5 倍累计。

### 白金会员

- 部分品鉴活动免费参与。
- 新品内测资格。
- 高端茶会优先邀请。
- 茶器鉴赏服务。
- 寄售优先展示。
- 寄售成交服务费按 7% 执行。
- 积分按 1.8 倍累计。

### 黑金会员

- 私享茶会。
- 大师作品优先预约。
- 限量茶器购买资格。
- 品牌新品共创资格。
- 私人收藏顾问。
- 专属会员编号。
- 寄售成交服务费按 6% 执行。
- 积分按 2 倍累计。

### 终身白金会员

- 永久白金身份。
- 永久会员编号。
- 年度会员礼。
- 优先参与品牌活动。
- 寄售成交服务费按 6% 执行。
- 积分按 2.5 倍累计。

### 终身黑金会员

- 永久黑金身份。
- 专属收藏编号。
- 限量茶器优先购买。
- 年度私人茶会。
- 品牌共创资格。
- 新品研发体验。
- 建立个人收藏档案。
- 寄售成交服务费按 5% 执行。
- 积分按 3 倍累计。

## 四、成长值规则

成长值用于会员等级评定，不等同于积分，也不能直接抵扣订单。

### 消费贡献

| 行为 | 成长值 |
| --- | ---: |
| 购买茶叶 | 实付 1 元 = 1 成长值 |
| 购买茶器 / 手作壶 | 实付 1 元 = 1.5 成长值 |

### 内容贡献

| 行为 | 成长值 |
| --- | ---: |
| 完成商品评价 | +50 |
| 上传茶评 | +100 |
| 分享朋友圈 | +50 |
| 小红书发布并通过审核 | +300 |

### 社交与活动贡献

| 行为 | 成长值 |
| --- | ---: |
| 邀请好友注册 | +200 |
| 好友首次购买 | +1,000 |
| 参加茶会 | +500 |
| 新品体验 | +300 |
| 寄售成功 | +500 |
| 置换成功 | +500 |

订单、内容和活动成长值须在审核或履约完成后入账；取消、退款或撤销时，按实际影响回退。

## 五、积分规则

- 积分自入账起 **24 个月有效**。
- 积分可用于适用订单抵扣。
- 积分可兑换茶叶、茶器、茶会及品鉴资格。
- 积分可兑换鉴定与寄售服务券。
- 每月可设置积分专享商品。
- 每季度可设置积分拍卖活动。
- 每年可设置会员积分兑换节。
- 积分冲正只能执行一次，人工发放必须保留对应证据。

## 六、嘉叶币规则

嘉叶币是春城嘉叶平台内的消费额度，适用范围以订单和商品配置为准。

- 仅限本人在适用商品订单中抵扣。
- 不可提现、转让、赠送或兑换现金。
- 嘉叶币抵扣部分不重复计入终身消费累计。
- 使用嘉叶币消费时，是否累计积分以商品和活动规则为准。
- 退款按原支付来源处理。

## 七、寄售与置换权益

### 1. 会员寄售

寄售成交服务费按实际成交价计算：

| 身份 | 服务费 |
| --- | ---: |
| 普通会员 | 10% |
| 银卡会员 | 9% |
| 金卡会员 | 8% |
| 白金会员 | 7% |
| 黑金会员 | 6% |
| 终身白金会员 | 6% |
| 终身黑金会员 | 5% |

计算方式：

> 成交服务费 = 实际成交价 × 适用费率  
> 会员结算额 = 实际成交价 - 成交服务费 - 委托单中已确认的其他费用

未成交不收取成交服务费。寄售价、适用费率和其他费用须在发布前由会员确认。

### 2. 茶器置换

置换与寄售是两条独立路径：

1. 提交茶器资料。
2. 完成鉴定与估值。
3. 展示参考估值、扣减项目和净置换价。
4. 会员确认并签署置换协议。
5. 完成权属转移。
6. 按净置换价发放嘉叶币。

置换本身不计入终身消费累计。嘉叶币只可在适用订单中使用，不可提现。

## 八、会员成长路径

品牌建议在会员中心展示以下成长路径：

> 喝茶人 → 爱茶人 → 茶人 → 藏茶人 → 鉴茶师 → 品牌共创者

对应的会员体验包括：

- **喝茶人**：注册、购买、完成第一杯茶的体验。
- **爱茶人**：持续品饮，开始记录口味和茶评。
- **茶人**：参加茶会、新品体验和品牌活动。
- **藏茶人**：建立茶叶、茶器和手作壶的收藏偏好。
- **鉴茶师**：参与鉴赏、寄售、置换及内容共创。
- **品牌共创者**：参与新品研发、联名和品牌长期建设。

## 九、运营建议

### 会员中心首页

建议固定展示：

- 当前年度会籍与下一等级进度。
- 终身身份与累计净实付金额。
- 成长值、积分、嘉叶币三项余额。
- 当前可用权益和即将到期积分。
- 最近 5 条积分与成长值流水。
- 会员活动、茶会和新品入口。

### 会员触达节奏

| 节奏 | 内容 |
| --- | --- |
| 注册当天 | 欢迎信息、会员规则、首次品饮推荐 |
| 生日月 | 生日礼及专属茶品推荐 |
| 每月 | 积分专享商品、茶评征集、活动预告 |
| 每季度 | 茶会、新品试饮、积分兑换活动 |
| 等级变更时 | 升级祝贺、权益说明、下一等级指引 |
| 积分到期前 30 天 | 到期提醒及可兑换商品推荐 |

## 十、品牌边界与执行说明

- 本方案适用于春城嘉叶母品牌。
- 爻 YÁO 商品默认不抵扣积分、不产生母品牌积分，也不参与会员折扣或满减，除非后台另行配置并公告。
- 具体权益受商品适用范围、活动名额、有效期、库存和服务区域影响。
- 会员等级、成长值、积分、嘉叶币和终身身份均以服务端账户记录为准。
- 退款、取消、撤销及违规行为会触发相应账户回退或权益调整。

## 十一、上线前需要统一的配置

项目中存在一处历史资料差异：`docs/mini-program-profile.md` 记录的年度门槛为 1,000 / 5,000 / 15,000 / 50,000，而当前会员生态配置 `ccjy-mall/mobile/sheep/helper/membership-ecosystem.js` 使用 10,000 / 30,000 / 80,000 / 200,000。

本方案按当前会员生态配置整理。正式上线前，应由品牌方确认唯一版本，并同步更新：

1. 小程序前端会员等级展示。
2. 后台会员等级和成长值规则。
3. 服务端等级计算与回退逻辑。
4. 会员权益、寄售费率和活动资格。
5. 会员规则页面、客服话术和对外宣传物料。
