# 「春城嘉叶」深度三轮闭环审核与升级实施方案

本方案在既有本地持久化与核心交易闭环基础上，针对新引入的 **D3.js 山场风土感官光谱可视化模块** 及全站跨视图深层交互进行**新一轮三阶段闭环审核与优化**，彻底打通「山场感知 → 寻味选器 → 茶席试饮 → 结席入囊 → 品茗评鉴 → 茶性进化」的完整数据飞轮。

---

## 一、 审美规范与交互准则

- **东方极简与宋韵留白**：延续宣纸暖白（`#FAF8F5`）、深林墨绿（`#1E2320`）与宋锦沉金（`#8F733E`）色彩体系，杜绝廉价促销标签，所有筛选项与状态反馈均融入器物与茶席语境。
- **D3.js 极坐标视觉调性**：五大名山产区各自拥有专属的矿物与草木色谱（武夷赭石、乌岽沉金、狮峰竹青、布朗古褐、太姥天青），点击极坐标顶点或产区卡片即可触发跨模块联动。
- **零断头路径原则**：任何筛选、搜索、结账、评鉴操作均提供即时反馈与下一步直达入口。

## 三、 三轮闭环优化核心内容

### 第一轮：D3.js 山场风土模块与五大产区商品库全映射闭环
1. **补齐五大名山产区馆藏代表茶商品**：
   - 审核发现此前山场风土模块中，西湖狮峰、勐海布朗山、福鼎太姥山尚未拥有独立的馆藏商品条目，且原产区商品 ID 存在映射偏差。
   - 在馆藏商品库中正式补齐**「狮峰翁家山·头春明前手炒龙井」**、**「布朗山老班章·古树纯料春茶饼」**与**「太姥山荒野·头春特级白毫银针」**三款完整商品档案（含冲泡度量衡、规制指标与风土物语），并将五大产区与真实商品 ID 一一精准绑定：
     - 武夷山正岩 ↔ `沉芳·武夷岩茶（正岩）`
     - 潮州乌岽顶 ↔ `诸心·凤凰单丛（便携泡袋装）`
     - 西湖狮峰 ↔ `狮峰翁家山·明前手炒龙井`
     - 勐海布朗山 ↔ `布朗山老班章·古树纯料青饼`
     - 福鼎太姥山 ↔ `太姥山荒野·头春白毫银针`
2. **D3 雷达维度联动市集风味检索**：
   - 在 D3 山场风土卡片中，不仅支持直接唤起该产区代表茶的商品详情弹窗与茶室试饮预约，还支持点击**「按此风土检索市集」**直接带着产区名跳转至市集视图，精准展示该山场下的全部茗茶。

---

### 第二轮：跨视图导航、商品直约茶席与订单复购闭环
1. **首页四柱金刚区精准筛选直达**：
   - 点击首页四大分类柱（`潮州手拉`、`凤凰单丛`、`武夷正岩`、`爻·茶简`），自动携带对应的分类与山场关键词跳转至市集视图并激活相应筛选条件，同时在市集顶部显示当前激活的风土/品类筛选状态条与一键重置入口。
2. **商品详情页「一键携茶预约茶室试饮」闭环**：
   - 在商品详情弹窗中，针对「山场原叶」与「爻 YÁO」茶品，在底部操作栏旁新增**「预约茶室试饮」**按钮；点击后自动关闭详情弹窗、将该茶品设为茶室预选茶并唤起包间预约弹窗，实现「先在茶室品鉴，满意再入囊」的高定零售体验。
3. **茶囊结席直达履历 & 历史订单一键复购**：
   - 在茶囊购物车结席成功界面，新增**「查看订单履历与物流」**快捷入口。
   - 在「茶事履历 — 商品订单」中，为每笔历史订单新增**「再次入囊复购」**按钮，点击即可将该订单内的茶品器物一键重新加入茶囊并给出雅致反馈。
4. **市集搜索空状态优雅兜底**：
   - 当用户在市集输入无匹配的搜索词时，展示宋韵美学的空状态提示卡，并提供「清除筛选 · 浏览全部器物」与「前往山场风土寻茶」双引导按钮。

---

### 第三轮：订单品茗评鉴反哺「个人茶性五维雷达」终极数据闭环
1. **订单内撰写「品茗评鉴与感官标签」**：
   - 扩展订单数据结构，支持为每笔订单记录用户的**品茗评鉴笔记（`reviewNote`）**与**实测口感标签（`reviewTags`）**（如 `岩骨花香`、`兰底幽香`、`蜜韵甜润`、`汤稠水厚`、`老枞苔味` 等），并同步持久化到本地存储。
   - 在「茶事履历 — 商品订单」卡片中提供交互式**「撰写/修改品茗评鉴」**折叠面板，用户勾选口感标签并保存后，可点击**「同步重塑我的茶性档案」**直接跳转至个人茶性五维雷达弹窗。
2. **个人茶性五维雷达实时读取订单评鉴**：
   - 升级茶性档案计算逻辑，自动聚合用户所有历史与新增订单中的商品属性及用户亲手撰写的订单评鉴标签，实时重算「焙火、香扬、回甘、稠滑、喉韵」五维分值与茶人雅号，形成「购茶 → 品评 → 茶性档案进化 → 小众茶精准推荐」的完整闭环。
3. **全量单元测试覆盖与构建验证**：
   - 扩充单元测试套件，验证五大产区真实商品映射、订单评鉴写入与茶性五维雷达动态重算逻辑，确保全站所有测试、TypeScript 编译与 ESLint 校验 100% 零错误通过。
